# AI Office Hours — Foundation

PHASE55 / Stage7 / Feature13. `/office-hours` is a local template workflow, not a validated model tutor or professor replacement. Course, topic, question, current understanding, sticking point, optional material excerpt and source are ephemeral React state. No network call, automatic persistence, email sending, memory mutation or external AI API.

Five modes organize learning: Explain (general study method only), Ask me questions, Hint first, Check my reasoning (not an automatic correctness judgment), Prepare professor question (student draft only). Exact supplied excerpts are displayed separately from general learning steps; references are student supplied, not authenticated. Absent material never becomes a grounded claim. Course policy, syllabus, grades, deadline exceptions and insufficient evidence lead to professor/TA confirmation. Changing any input invalidates the prior result.

This is deliberately Foundation, not Beta: subject-specific explanations, conversational model grounding and student learning outcomes remain unvalidated. Future model integration requires an independent quality/safety gate, evidence-span checks, prompt-injection tests and explicit privacy review. Tests cover missing fields, mode behavior, grounding separation, escalation and non-impersonation.
