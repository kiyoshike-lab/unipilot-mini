# Professor Email — Stage5 Template Beta

Feature10 **Beta** is scoped to a local template assistant at `/email`; it is not unrestricted AI writing or automatic email sending. Input: optional recipient name, recipient role, course, purpose, facts/datetime, requested action and tone. Presets:absence,lateness,assignment consultation,retake consultation,meeting request,question,other. Tones:丁寧/簡潔/相談的.

The actual workflow always labels output **Template draft — AI生成ではありません**. It remains available without an API; there is no attempt to call an external/local LLM followed by an undisclosed fallback. Facts and requested action are quoted from input without inventing dates/reasons/deadlines/names/documents/university rules/promises. A preset only selects the subject's purpose label; it does not assert that an absence, illness or submission has occurred. Missing values remain explicit placeholders, not fabricated facts. Source facts themselves are user-supplied and unverified.

Subject/body are always previewed and editable. Changes to source inputs mark the existing preview stale and disable Copy until the student explicitly regenerates it. Regeneration asks before replacing an edited preview. Copy uses the currently edited subject/body, never sends an email. Clipboard failure gives manual-copy guidance. Clear resets component state after confirmation; nothing is stored on a server or in localStorage. No recipient addresses, mail APIs, mailto send flows, credentials or automatic commitments are created.

`frameEmailFacts` is an **unconnected future integration contract**, tested but not used by the UI. It serializes input as JSON beneath a rule that embedded instructions are data and missing facts/commitments must not be supplied. The small UTF-8 budget rejects oversized prompts without truncating facts. It is not evidence that the current Foundation model can safely perform email generation, nor permission to enable such an API path.

Tests cover all presets, missing professor/date/facts, absence/lateness/retake/assignment/meeting, three tones, no invented facts/promises, future prompt delimiting/budget refusal, editable browser preview, stale-copy blocking, clear and offline Template disclosure. This is local functional and fake-fact safety evidence; real student usability/quality and authenticated Live QA remain unverified. Automatic sending and external AI APIs are OFF.
